## Workspace Naming Convention

```
KLR-{BusinessUnit}-{Region}-{Environment}-PowerBI-{Layer}-WS

Components:
  KLR          = Keller Group prefix
  BusinessUnit = RO (Romania), UK, etc.
  Region       = NorthEurope, WestEurope, EastUS
  Environment  = Dev, QA, Prod
  Layer        = SM (Semantic Models), Reports, DL (Data Lake)

Examples:
  KLR-RO-NorthEurope-Dev-PowerBI-SM-WS
  KLR-RO-NorthEurope-QA-PowerBI-Reports-WS
  KLR-RO-NorthEurope-Prod-PowerBI-SM-WS
```
